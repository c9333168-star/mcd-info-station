# 麦麦情报站（mcd-info-station）

基于 **麦当劳中国官方 MCP** 的全场景吃喝情报中枢 · 麦当劳程序员节创意开发大赛参赛作品

> 活动雷达只会告诉你"有什么活动"，麦麦情报站还会告诉你：
> **哪些活动快结束了、哪些券要过期了、临期积分先抽奖还是先换货、今天值不值得吃。**

## 这是什么

一个 WorkBuddy Skill，把麦当劳中国 MCP（`mcp.mcd.cn`）的 **活动日历、优惠券、积分、积分抽奖、主题活动预约** 五类能力串成一套情报工作流：

**先校准时间 → 拉取五线情报 → 交叉联动分析 → 输出每日情报简报 → 可选深入操作（领券 / 抽奖 / 兑换 / 预约）**

## 目标用户

- 想吃麦当劳但总错过活动 / 忘记用券的普通会员
- 积分攒了一堆不知道怎么花最值的积分玩家
- 对主题派对、品鉴会感兴趣但不知道怎么查怎么约的用户

## 安装方法

1. 申请 MCP Token：前往 [open.mcd.cn/mcp](https://open.mcd.cn/mcp)，手机号登录后在控制台点【激活】复制 Token。
2. 配置 MCP：将 `mcp-config.example.json` 的内容粘贴进你的 MCP Client（WorkBuddy / Claude Code / Cursor 等支持 Streamable HTTP 的客户端），把 `${MCD_MCP_TOKEN}` 替换为你的真实 Token（建议用环境变量）。
3. 安装 Skill：把整个 `mcd-info-station` 目录复制到 WorkBuddy 的 Skills 目录（如 `~/.workbuddy/skills/mcd-info-station`）。
4. 开聊：对 AI 说「今天麦当劳有什么值得关注的」即可。

## 核心差异点

单一信息源是"复读机"，交叉分析才是"情报站"：

| 交叉 | 产出 |
|---|---|
| 券 × 活动日历 | 最佳食用窗口（"半价盒活动期间用这张券更省"） |
| 积分 × 抽奖 × 商城 | 临期积分最优去向（先抽还是先兑） |
| 活动日历 × 主题派对 | 活动落地为可预约行动（城市→门店→场次） |
| 时间校准 × 一切 | 全部"进行中/临期"判断基于 `now-time-info` 真实时间 |
